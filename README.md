# 📊 Applied Machine Learning Portfolio

This repository contains end-to-end Machine Learning projects and data analysis workflows built using Python.

It demonstrates practical skills in:
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning Model Development
- Model Evaluation & Optimization

---

## 📁 Projects

### 🏠 House Price Prediction
Regression model using Random Forest and XGBoost with feature engineering and hyperparameter tuning.

### 💳 Fraud Detection
Imbalanced classification problem solved using SMOTE and LightGBM.

### 🧬 Diabetes Classification
Logistic Regression model with cross-validation and outlier handling.

### 🌸 Iris Classification
Random Forest classifier achieving ~98% accuracy.
