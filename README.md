📊 Applied Machine Learning Portfolio

A production-oriented Machine Learning portfolio demonstrating end-to-end problem solving on real-world structured datasets.

This repository focuses on building reproducible ML systems, not just training models — including data preprocessing, feature engineering, model selection, evaluation strategy, and performance optimization.

🎯 What This Repository Demonstrates

This project focuses on real-world machine learning engineering capabilities:

Translating real-world problems into ML formulations
Handling messy datasets (missing values, imbalance, noise)
Selecting appropriate models and evaluation metrics per problem type
Designing reproducible and modular ML workflows
Applying business-oriented thinking to model evaluation
📁 Projects
🏠 House Price Prediction (Regression)

End-to-end regression system for real estate price estimation using ensemble learning.

Models: Random Forest, XGBoost
Techniques: Feature engineering, hyperparameter tuning (GridSearchCV)
Evaluation: RMSE, MAE, R²

📌 Impact: Supports automated property valuation systems and pricing decision workflows.

💳 Fraud Detection (Imbalanced Classification)

Financial transaction fraud detection on highly imbalanced data.

Model: LightGBM
Techniques: SMOTE oversampling, feature scaling
Evaluation: ROC-AUC, Precision/Recall trade-off

📌 Impact: Reduces financial risk by identifying fraudulent transactions in real-time systems.

🧬 Diabetes Prediction (Healthcare ML)

Medical risk prediction model for early diabetes detection.

Model: Logistic Regression
Techniques: Outlier handling, robust scaling, cross-validation
Evaluation: Accuracy, F1-score, ROC-AUC

📌 Impact: Supports early-stage medical screening decision systems.

🌸 Iris Classification (Baseline ML)

Multi-class classification benchmark for model validation and comparison.

Model: Random Forest
Evaluation: Accuracy ~98%, confusion matrix analysis

📌 Purpose: Baseline model to validate classification pipeline correctness.
